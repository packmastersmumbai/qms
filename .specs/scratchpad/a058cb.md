## Technical Analysis / Recommendations
- Rendering: inline `<svg>` with one `<g>` transform layer; blocks=`<rect>`, labels=`<text>`.
  Pan/zoom = CSS transform on the `<g>`. NO library (GAS blocks CDN). svg-pan-zoom self-hosted only if pinch fiddly.
- Location coding: `^[ABC]\d{3}$` (floor letter A/B/C + 3-digit sequential, zero-padded). Bay is a
  display/group column only — NEVER parsed from the ID, never in capacity math. Renumber-safe.
- Fit: capacity(P@L)=min(floor(L.vol/P.eachVol), floor(L.maxWt/P.eachWt)); pallet fit=TI×HI on product.
  Phase-1 slots = 1 pallet each → geometry only converts receipt qty→pallet count (qty÷perPallet).
- QR: feature-detect `'BarcodeDetector' in window` → getUserMedia stream + rAF detect loop; else tile-pick.
- Heatmap: occupancy ratio → sequential 5-stop scale (empty→full), computed light+dark; class-swap on rect fill.
